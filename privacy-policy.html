Privacy Policy — Subtitle Capture Extension

Last updated: 17 July, 2026

What this extension does

Subtitle Capture is an internal tool that captures live video captions displayed on internal company web pages, so they can be reviewed and copied by the user.

What data is collected

  • The caption/subtitle text displayed on the page during a capture session.
  • The title and URL of the tab where the capture was started (used only to label sessions in your history list).
  • Timestamps marking when each capture session started and ended.

No other page content, personal information, browsing history, keystrokes, or credentials are accessed or collected.

How data is stored

All captured data is stored locally on the user's own device, using Chrome's built-in storage APIs (chrome.storage.local and chrome.storage.session). Nothing is sent to any external server, and the extension makes no network requests of its own.

Retention

Captured sessions are automatically deleted after 48 hours. Uninstalling the extension, or clearing the browser's extension data, immediately removes all stored data.

Data sharing

No data is shared with, or sold to, any third party. There is no analytics, tracking, or advertising code in this extension.

When data is captured

The extension only reads caption text when the user explicitly clicks "Start Capture." It is inactive on all pages by default and takes no action until the user starts it.

User control

Users can stop a capture at any time, copy or delete any session from the history list, and remove all data by uninstalling the extension.
